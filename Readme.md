# お絵かき招金（まねきん）

絵描きさんのための、**無料ブラウザ3Dポーザー**です。マネキンとVRMモデルにポーズを付けて、PNGで書き出し、そのまま作画資料・下絵に使えます。

インストールも、アカウント登録もいりません。

**▶ 使う： https://oekaki-manekin.github.io/app/**
**公式ページ： https://oekaki-manekin.github.io/**

---

## できること

- **ポーズを付ける** ── 関節をクリックして回すFKと、手足を引っ張って動かすIKを切り替え。ピン留め、可動域制限、左右反転、Undo / Redo
- **指まで動く** ── パー・グー・指差し・ピースなどのプリセットと、自作プリセットの保存
- **VRMを読み込む** ── VRMファイル（0.x / 1.0）をドラッグ&ドロップ。マネキンで作ったポーズをそのまま適用でき、逆もできます
- **複数体を並べる** ── 最大4体。マネキンとVRMを混ぜられます
- **構図を決める** ── 視点プリセット、画角（mm相当）調整、キャンバス枠、アイレベル線、接地の目安表示、光源の方位・高さ調整
- **線を拾いやすくする** ── 輪郭線表示（太さ・強さの調整可）、トゥーン調、グレースケール、シルエット
- **書き出す** ── PNG書き出し（背景透過・キャンバス枠内のみに対応）、多角度一括書き出し、ポーズのJSON保存・読込

対応環境は **PCの最新 Chrome / Edge** です。スマートフォン・タブレットは対象外です。

## 「外部に送信していない」ことの確かめ方

このツールは、読み込んだVRMモデルも、作ったポーズも、**すべてブラウザの中だけで処理します。**外部のサーバーへ送信することはありません。アクセス解析も入れていません。

その説明を信じていただく必要はありません。**このリポジトリで確かめられます。**

```bash
# 外部へ通信するAPIを使っていないことの確認（ヒット0件）
grep -rnE "\bfetch\(|XMLHttpRequest|WebSocket|sendBeacon|EventSource" app/src/

# 外部ホストのURLが埋め込まれていないことの確認（ヒット0件）
grep -rnoE "https?://" app/src/

# アクセス解析の類が入っていないことの確認（ヒット0件）
grep -rniE "gtag|googletagmanager|analytics|sentry|clarity" app/src/
```

依存しているライブラリも2つだけです（`app/package.json`）。

| ライブラリ | 用途 |
|---|---|
| [three.js](https://threejs.org/) | 3D描画 |
| [@pixiv/three-vrm](https://github.com/pixiv/three-vrm) | VRMモデルの読み込み |

どちらもビルド時にまとめられるため、ページを開いたあとに外部へ取りに行くものはありません。LPも、外部フォントを含めて一切の外部リソースを読み込まない構成にしています。

## 開発

```bash
cd app
npm ci
npm run dev     # 開発サーバーを起動
npm run build   # 型チェック＋本番ビルド（app/dist/ に出力）
```

Node.js 20 以上で動作を確認しています。

## リポジトリの構成

```
├─ app/           アプリ本体（Vite + TypeScript）
│  ├─ src/          ソース
│  ├─ index.html    ビルドの起点
│  └─ package.json
├─ lp/            公式ページ（単一のHTML。外部リソースなし）
│  ├─ index.html
│  ├─ images/
│  ├─ ogp.png
│  └─ robots.txt
├─ LICENSE.md     ソースコードの利用条件
└─ Readme.md      このファイル
```

公開は GitHub Actions が行い、`lp/` をサイトのルートへ、`app/dist/` を `/app/` へ配置します。
