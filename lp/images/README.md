# LP画像の差し替え手順

このフォルダの画像は**すべて仮画像（プレースホルダ）**です。
**同じファイル名で上書きするだけ**でLPに反映されます。HTMLを触る必要はありません。

## 差し替え一覧

| ファイル名 | 掲載場所 | 比率 | 推奨サイズ | 内容 |
|---|---|---|---|---|
| `hero.png` | トップの大きな枠 | **16:9** | 1920×1080 | ポーズ付け→輪郭線→PNG書き出しの流れが分かる1枚 |
| `step-01.png` | 使い方 STEP 01 | **4:3** | 1600×1200 | ギズモでポーズ操作中の画面 |
| `step-02.png` | 使い方 STEP 02 | **4:3** | 1600×1200 | 構図調整とPNG書き出しの画面 |
| `step-03.png` | 使い方 STEP 03 | **4:3** | 1600×1200 | 書き出し画像を下絵にした作画例 |
| `vrm-pose.png` | VRM対応セクション | **4:3** | 1600×1200 | 自作VRMにポーズを付けた画面 |

## 守ってほしいこと

1. **ファイル名と拡張子は変えない**（`.png` のまま）。名前が変わるとLPから見えなくなります。
2. **比率を合わせる。** 表の比率と違う画像を入れても表示自体は崩れませんが、`object-fit:cover` で上下または左右が切り落とされます。見せたいものが端にある場合は、あらかじめ比率どおりにトリミングしてください。
3. **サイズは推奨値以上なら何でも構いません**（大きい分には縮小されるだけ）。ただし1枚あたり **500KB以下** を目安に。重いとLPの表示が遅くなり、検索順位にも影響します。
4. **文字が写り込む場合は読める大きさで。** LP上では横400px前後まで縮むので、UIの細かい文字は潰れます。見せたい部分は拡大して撮るか、その部分だけをトリミングしてください。

## alt属性（画像の説明文）について

alt属性は**画像検索とアクセシビリティのためにHTML側へ既に書いてあります**。
画像の内容を大きく変えた場合（例：STEP 03を作画例ではなく別の画面にした）は、`lp/index.html` の該当 `<img>` の `alt="..."` も直してください。中身と説明が食い違うと検索評価が下がります。

## 動画にしたい場合（heroのみ）

`hero.png` の位置は動画にもできます。`lp/index.html` の該当 `<img>` 1行を次に置き換えてください。

```html
<video src="images/hero.mp4" poster="images/hero.png" autoplay muted loop playsinline></video>
```

`poster` があるので、動画の読み込み中は `hero.png` が表示されます。

## OGP画像は別扱い

SNSでシェアされたときのサムネイル（OGP画像）は、このフォルダではなく **`lp/ogp.png`** です（1280×630）。
差し替える場合も同じく `ogp.png` の名前のまま上書きしてください。推奨サイズは1200×630です。
